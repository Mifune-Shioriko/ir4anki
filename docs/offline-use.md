# Debian 13：离线使用与手动同步

完整 Debian 13 上运行本地 Python 服务、官方 Anki 25.2.7 引擎和已构建前端。
浏览器访问本机 `http://127.0.0.1:8901`。连续数日断网无需 npm/pip、CDN、PWA 或远程 API。
同步服务器及两位用户的现有独立账号保持原样；不要复制另一人的集合、凭据或阅读状态。

## 联网准备一次

按现有安装文档准备依赖、构建产物、独立 collection/state/corpus/media，并完成一次明确的同步。
使用本地教材和媒体；完整 Debian 的系统字体提供界面字体回退（中文可预装 fonts-noto-cjk）。
UI 脚本、Material 图标、Markdown/KaTeX 及 KaTeX 字体由 Vite 打包为本地资产；没有运行时字体 CDN。
服务模板已移除 `network-online.target` 依赖。正常登录后 user service 可离线启动；本次修改未安装模板或重启服务。
离线期间不执行 install/update。源码更新、依赖安装或首次同步只在操作者联网后主动安排。

## 默认策略

新增可选 `ANKI_SYNC_POLICY`，**未配置时为 `manual`**。不需要修改现有凭据配置。
`manual` 下启动、评分、下一项、阅读、结束、编辑、新建、删除及撤销不尝试远程同步，也不设同步定时器。
`legacy` 是明确的旧自动同步调用入口兼容选项，保留节流/撤销延期；原生评分本身仍只作本地提交。
不要为日常离线机器启用 legacy。AnkiConnect 模式需要本机桌面 Anki；本任务的离线验收使用 pylib。

原生 SQLite 保存所有答案、revlog、FSRS 和笔记变更。单槽 journal 只保护最后一次评分的撤销，
不是待上传答案队列。下一次评分在本地结束上一撤销槽，不丢弃原生待同步变更。
journal/业务状态原子替换、fsync、SQLite 事务及崩溃恢复保持有效。
日切换的 `lastUnburied` 是引擎维护标记，不属于评分撤销；撤销保留当前标记，仍严格验证卡片、revlog、FSRS 和调度配置。

## 联网后主动同步

导航栏“手动同步”打开确认窗口，不要求学习者输入管理员令牌。打开及取消只读取状态，
勾选结束最后一次评分撤销的确认，再点“确认并同步”才会调用 `/api/local/sync`。
该入口仅允许直连本机回环 peer、回环 Host（127.0.0.1 / localhost / ::1）和完全同源的 Origin，
并要求 JSON、自定义确认头及显式 `commit_undo: true`；拒绝 Forwarded / X-Forwarded-* 和跨站 Fetch Metadata。
这些检查防止跨站表单、通配 CORS 和 DNS rebinding 将本机服务作为同步代理。
现有 `/api/engine/*` 管理操作（含原有同步、备份、导出、下载和统计）仍要求管理员 bearer token。
普通入口只能同步本机已配置集合及账号，不接受账号、endpoint 或全量同步方向字段。
服务器要求完整同步时仍报错，必须由操作者在桌面 Anki 明确决定上传或下载。

信任边界是同一台机器上可直接访问服务的本地用户与应用来源，并非多租户用户身份鉴权。
本机恶意进程或同源脚本可伪造这些请求；本地服务与集合应按现有操作系统用户隔离。
此入口不支持远程访问或反向代理，也不把代理报告的客户端地址视为可信证据；
不要配置代理把外部请求改写成无转发头的 localhost 同源请求。
没有配置同步账号时官方引擎仍失败关闭，不创建或泄露凭据。

同步中暂停学习。失败后关闭窗口即可继续离线学习；可能已有部分变更导出，旧撤销不能恢复。
继续评分只建立新的撤销槽，原生数据库变更留待下一次手动同步。
状态分别记录尝试、集合阶段完成、集合及媒体全部成功、失败阶段；媒体完成前不报告整体成功。
`local_changes_pending` 根据原生 usn 判断集合是否有变更；媒体可能有变更，不伪造精确上传计数。
同步状态写入集合旁 `.ir4anki-sync.json`，绑定集合，重启可读；该状态文件不是答案存储，损坏不阻止本地使用。
服务器要求 full sync 时显式报错，操作者停止服务后在桌面 Anki 决定方向，不自动覆盖。

## 媒体与数据边界

**外链卡片图片、音视频、iframe、模板脚本/CSS，以及语料中的远程图片仍依赖原网站。**
应用不会扫描后自动下载任意外链。出门前检查自己使用的笔记字段、卡片模板、CSS 和 Markdown：
`http://`、`https://`、`//` 的 `src`/`href`/`url()` 与 Markdown 图片地址都是需要人工检查的候选项。
普通文字链接可以离线保留，但其目标不能离线浏览。把必需媒体经现有上传/Anki 媒体导入放到本地，再改为本地地址；
用全新浏览器上下文断外网测试，不依赖浏览器旧缓存。缺失/外链媒体不影响评分持久化，但内容可能不完整。

Anki 同步不上传 ir4anki 阅读清单、reading.db、轮次/流程和教材 corpus；一台学习电脑作为阅读状态写入端。
沿用已有备份工具与一致性快照约束，未新增备份体系或多设备阅读合并。
保持本机时钟/时区正确；真实五日与目标硬件延迟仍需实际试用，本仓库测试采用加速日历的隔离夹具。
